# Eingang

Hier einfach alles reinschreiben, was dir auffällt – Bugs und Wünsche, frei formuliert, eine Zeile oder ein Absatz je Eintrag.
Format (nur eine Hilfe, kein Muss):

```
- [Bug|Wunsch] Was passiert / was du willst. (wo: clau | Qode | Proxy | Übersetzung; Meldung/Bildschirm, falls vorhanden)
```

Der Triage-Agent (`subagenten/subagent_triage.md`) räumt diese Datei auf: Einträge wandern nach `TRACKER.md`, hier bleibt nichts stehen.
